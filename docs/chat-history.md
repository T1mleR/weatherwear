# Цель проекта: WeatherWear AI - умный стилист по погоде

## История идеи

WeatherWear AI — умный стилист. Берет погоду и генерирует советы по одежде и слоям.

Идея выросла из простой ежедневной проблемы: утром нужно быстро понять, что надеть, а не смотреть прогноз и потом самому переводить температуру, ветер и осадки в конкретный набор вещей. Приложение должно делать этот перевод за пользователя.

## Что должен уметь продукт

- Получать актуальную погоду для выбранного города или текущей геолокации.
- Учитывать температуру, ощущаемую температуру, ветер, осадки, влажность и UV.
- Генерировать понятный совет по одежде: верх, низ, обувь, верхняя одежда.
- Предлагать слои (base / mid / outer), а не одну общую фразу «одевайся теплее».
- Давать короткий комментарий «почему именно так» на основе погоды.
- Позволять уточнять контекст: прогулка, учёба, офис, спорт, вечер.

## Принципы

- Совет должен быть конкретным и проверяемым, а не абстрактным.
- Один основной outfit на текущий момент + опциональные альтернативы.
- Ошибки погоды и API не должны ломать экран: пользователь видит понятный fallback.
- Сначала ценность (советы по слоям), потом инфраструктура (хранение, аккаунты).

## Текущий статус

Проект стартует как Next.js-приложение. Документация, роли и контракт API живут в `docs/`. Реализация идёт итерациями: Mock → OpenAPI → In-Memory → SQLite.
